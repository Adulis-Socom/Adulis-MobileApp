## What was fixed

1. Every PDF was rebuilt from the authoritative November editable sources, then rewritten with a clean PDF object/xref structure.
2. Archive paths and design filenames were shortened to reduce Windows path/extraction failures. The full document title remains inside each design and in `FILE_INDEX.csv`.
3. Python cache files, temporary render work, nested historical ZIPs and renderer font binaries were removed from the deliverable. They are not needed to use the development manuals.
4. Current authority material was separated from historical evidence to prevent old October rules being mistaken for current rules.
5. JSON, Markdown, SVG and PDF structures are validated before packaging.
