  identity on every read.

  publication under an honest "Newest first" label, two-column grid with the server's price span
  and availability in words, cursor pagination to an explicit end, Product and Seller navigation

## 9. Security findings

- **HIGH (fixed):** crafted list cursors could pass the shape check and make Postgres refuse them
  (impossible dates, int overflow) -> 500 (ON-20261111-032). Cursors are now validated as real
  round-tripping instants and int4-bounded; 400 `CURSOR_INVALID`.
- MEDIUM (fixed): storefront views counted on every re-read (ON-20261111-031); PATCH could
  withdraw a reserved Variant (ON-20261111-004).
- Isolation verified: Market-scoped Seller identity on every Seller read, Shop limited to the
  requester's Market (another Market's price never shown, natively and in API tests); PRIVATE
  Scenes never listed; no Seller-private API used for Buyer discovery; all new public reads
  `no-store`; no new write path, no tracking or impression event, For You personalisation off.
- Open, low: Shop and Seller-products cursors carry a Product id / creation instant
  (ON-20261111-051, -037).
